Simple Todo App


モダンなWeb開発の学習を目的とした、フルスタックのTodo管理アプリケーションです。
ユーザー認証（ログイン維持機能付き）と、データベースによるデータ永続化を実現しています。

🚀 主な機能

ユーザー認証: ログイン/ログアウト機能。

ログイン維持: localStorage を活用したセッション管理（最終操作から5分間有効）。

Todo管理: タスクの追加、完了状態の切り替え、削除。

バリデーション: HTML5およびJavaScriptによるメール形式チェック。

レスポンシブ: ブラウザ上で快適に動作するUI。


🛠 使用技術

Frontend: HTML5, JavaScript

Backend: Node.js, Express

Database: PostgreSQL
